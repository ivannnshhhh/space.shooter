# Space Shooter 🚀

A cute arcade-style space shooter game controlled using hand gestures through a webcam.

## Features

* Hand gesture controls
* Real-time hand tracking
* Enemy spaceships and UFOs
* Boss battle
* Laser shooting system
* Explosions and particle effects
* Background music and sound effects
* Camera view integrated into the game

## Requirements

* Python 3.10+
* Webcam
* Pygame
* OpenCV
* NumPy
* MediaPipe

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Controls

The game uses hand gestures detected through the webcam.

* Move your hand to control the spaceship
* Use the detected gesture to interact with the game
* Hand gestures are also used to navigate the game menu
